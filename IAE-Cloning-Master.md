# 1. UNIVERSAL REPAIR-LOOP LAW

This is the central control of the entire system.

Every production stage follows:

**DO → CHECK/AUDIT → PASS?**

- **YES → CONTINUE**
- **NO → IDENTIFY CAUSE → REPAIR/CORRECT/ADD/REMOVE → RE-CHECK → AUDIT**
- If still FAIL → **REPAIR → RE-AUDIT**
- Continue until the applicable requirement is PASS.

A failure is never an instruction to abandon the production sequence. It is an instruction to repair the current dependency and then audit it again.

### Mandatory rule

> **Repair without re-audit is incomplete. Audit without repair after a known failure is incomplete. PASS without evidence is invalid.**

If a repair may affect other components, run the required affected regression; if impact cannot be isolated, run the complete relevant regression.

## LOCKED LECTURE DENSITY RULE

Every new Lecture must be partitioned after Academy Numbering and before UI production.

1. **Maximum Main Topics per Lecture = 2.**
2. **Maximum Academic Subtopics per Lecture = 14.**
3. All eligible Red + Green academic subtopics must be preserved; none may be skipped, duplicated, silently merged, or partially omitted.
4. If the complete Red + Green sequence contains fewer than 14 subtopics, approved **Blue Mastery** content may fill the remaining capacity.
5. Blue filler must remain inside the Main Topics already assigned to that Lecture.
6. Blue-only content may not create a new Main Topic or open a new Lecture.
7. Existing approved Blue syllabus items remain preserved.
8. If fewer than 14 remain after all valid Blue enrichment is exhausted, do **not** invent filler merely to reach 14.
9. Academic partition always has priority over visual balancing.
10. Lectureization must be audited before coding and re-audited after any repair affecting the partition.

Formula:

**≤ 2 Main Topics + ≤ 14 Academic Subtopics → Red/Green complete → if <14, Blue Mastery may fill → Audit/Repair until PASS.**

## FINAL READINESS TEST METHODOLOGY

Readiness Test is a **Test-Readiness teaching system**, not merely a question bank. It must prepare the learner to face the lecture test/examination without hesitation or fear.

Required sequence:

**Recall → Understanding → Method → Guided Practice → Error Correction → Independent Practice → Mixed Practice → Test Simulation → Readiness Result**

Each stage must use the locked lecture content. Wrong answers must trigger useful correction/explanation rather than a bare “wrong” message. The final stage must establish whether the learner is Test Ready and identify weak areas when not ready.

## FINAL PRACTICAL WORK METHODOLOGY

Where Practical Work is applicable, each listed practical must include lecture-style instructional support, not only a title or short answer. Minimum structure:

**Objective → Principle → Apparatus/Materials → Safety Measures → Step-by-Step Methodology → Observation/Recording → Calculation → Model Solution → Common Errors → Review**

The purpose is to let a learner understand how to perform the practical, why the steps are used, how to stay safe, and how to write/interpret the result.
