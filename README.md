IAE — Imperial Academy of Education

This repository serves as the private master repository of the Imperial Academy of Education (IAE).

It contains the authoritative academic structure and source files for Imperial Academy educational programs, including:

- First-year academic programs
- Subjects and lectures
- HTML, CSS, and JavaScript files
- Visual Atlas materials and academic visuals
- Supporting assets and resources

This repository is maintained as the Imperial Academy’s private master source.

Student access will be provided separately through published educational pages and, in the future, through the Imperial Academy’s enrollment and authentication system.
