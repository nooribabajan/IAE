BEFORE / AFTER RECONCILIATION

Source preservation proof

The report compares source bytes, basic structural inventories, and exact unchanged prefix/suffix. Counts are not treated as proof by themselves: every removed byte must be explained by the authorized snippet. A syntax/behavior pass is not claimed unless separately run in the target environment.

SAFETY CONTRACT

  • Input files are read in this browser; this page contains no upload endpoint or external library.
  • Every finding must be assessed against the code element's assigned role and actual contribution; overrides and duplicate declarations require review.
  • Unreferenced code and unmatched selectors must be challenged against their assigned role. On-demand functions, reflection, templates, routes, and external files must be explicitly accounted for; unexplained or ineffective code is flagged for removal review.
  • Analysis findings are not proof of correctness or vulnerability. No source is deleted automatically.
  • Large-file processing is bounded where practical; test changes in version control and run real project tests.
