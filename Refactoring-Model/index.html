CLEANUP LIMITS

  • Files are processed locally in this browser.
  • The automatic pass deduplicates safe CSS declarations/rules, removes simple class/ID rules with no static references, removes declaration-only const/let bindings with primitive literal values, and compacts whitespace in valid embedded JSON without changing string contents or keys. Dynamic markup or dynamic code disables the relevant removal pass; arbitrary HTML/JavaScript dead code is not guessed.
  • Uncertain code, comments, dynamic behavior, and conditional rules are preserved by this pass.
  • The original source remains unchanged; download the cleaned copy only after reviewing it.
