    6. Limitations and safety

    • Dead-code detection is approximate. A symbol not found by text search may still be used through reflection, dynamic imports, templates, dependency injection, framework conventions or generated code.
    • Runtime observation covers only the tested path and browser environment. Unexecuted code is not automatically useless.
    • Python, Java, Kotlin, TypeScript and other languages receive heuristic source inspection here, not full compiler-grade parsing.
    • This page does not bundle every refactoring framework or AI assistant. It provides a common local workbench and optional API adapters.
    • Keep backups and run the project's own tests/build before accepting a refactor.
