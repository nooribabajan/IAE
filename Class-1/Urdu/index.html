2. Paste academic text

No JSON writing required. Hierarchy-first parsing: # = course title, ## = topic, ### = subheading, deeper Markdown headings = nested subheadings. Numbered headings use 1., 1.1, 1.1.1, etc. First body paragraph is stored as definition; subsequent paragraphs, examples, divisions, formulas, numbered steps, bullet lists, tables, and other supporting material go under explanation. Explicit Definition: and Explanation: labels are respected. JSON retains recursive nesting; the legacy HTML template receives a flattened display-compatible view. Parsing preserves source text and does not judge academic quality.
