Academic Content Executor v2.3

Audit the template, organize academic text into editable JSON, validate the structure, and build a separate HTML output. The original template file is never modified.

1. Choose the template

Select your working copy of Template-v2.html.

No template selected.

2. Paste academic text

No JSON writing required. Builds a hierarchy: # = course title, ## or 2.1 = topic, ### or 2.1.1 = subheading, and #### = deeper subheading (flattened with its parent path for template compatibility). Paragraphs become definitions; labeled and bullet lists become subtopics. Numbered sections (1., 2.) become topics; numbered children (1.1) become subtopics. Plain-text headings are also detected. Learning-outcome bullets stay in course outcomes. The organizer is deterministic, not generative AI, so inspect the JSON before building.

3. Generate the new HTML

Version 2.3 fixes numbered-heading hierarchy, recognizes plain-text headings, fills missing definitions with clearly marked review placeholders, and adds stronger structure diagnostics; it retains the template audit and output-integrity checks. It does not rewrite subject-specific code outside the central academic bank; use the template for the same subject unless you separately adapt those features.
